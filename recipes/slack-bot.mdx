A Slack bot that remembers what is said in each channel and answers questions about it when mentioned.

## How isolation works

`session_id` does **not** keep channels apart. `recall` searches everything the calling identity can see. To stop `#sales` recalling `#hr`, give each channel its own Tex identity: `user_id="slack-<channel_id>"`. The API key needs an impersonation scope (`impersonate_user`, or an owner `"*"` key). See [Per-user clients](/sdk/per-user-clients).

For memory shared across several channels or people, use [scopes](/sdk/scopes) instead.

## Code

```python bot.py
import os
from datetime import datetime, timezone
from functools import lru_cache

from slack_bolt import App
from slack_bolt.adapter.socket_mode import SocketModeHandler
from tex import Tex

app = App(token=os.environ["SLACK_BOT_TOKEN"])


@lru_cache(maxsize=512)
def tex_for_channel(channel_id: str) -> Tex:
    """One Tex identity per channel, so channels never see each other's memory."""
    return Tex(
        api_key=os.environ["TEX_API_KEY"],
        base_url=os.environ["TEX_BASE_URL"],
        org_id=os.environ["TEX_ORG_ID"],   # required on SDK 1.2.0–1.2.1; recommended on 1.2.2+
        user_id=f"slack-{channel_id}",
    )


def slack_ts_iso(ts: str) -> str:
    """Slack message ts ("1726300000.123456") -> ISO-8601 UTC."""
    dt = datetime.fromtimestamp(float(ts), tz=timezone.utc)
    return dt.isoformat().replace("+00:00", "Z")


@app.event("message")
def remember_message(event, say):
    """Remember every non-bot message in the channel."""
    if event.get("subtype") or event.get("bot_id"):
        return
    channel = event["channel"]
    tex_for_channel(channel).conversations.remember(
        [{
            "role": "user",
            "text": f"<@{event['user']}>: {event['text']}",
            "timestamp": slack_ts_iso(event["ts"]),
        }],
        session_id=f"slack-{channel}",
    )


@app.event("app_mention")
def answer(event, say):
    """When mentioned, answer from this channel's memory."""
    query = event["text"].split(">", 1)[-1].strip()
    if not query:
        say("Ask me something — I'll dig through this channel's memory.")
        return

    channel = event["channel"]
    tex = tex_for_channel(channel)
    hits = tex.recall(query, session_id=f"slack-{channel}", top_k=5)
    if not hits.hits.turns:
        # Quiet channels: conversations idle past the inactivity window (30 min by default) move to long-term memory.
        hits = tex.recall(query, session_id=f"slack-{channel}", top_k=5, mode="deep")

    if not hits.hits.turns:
        say(f"<@{event['user']}> I don't have anything relevant in memory yet.")
        return

    body = "\n".join(f"• {h.text}" for h in hits.hits.turns[:3])
    say(f"<@{event['user']}> here's what I remember:\n{body}")


if __name__ == "__main__":
    SocketModeHandler(app, os.environ["SLACK_APP_TOKEN"]).start()
```

## Patterns

- **Channel vs private memory.** `slack-<channel>` is shared by everyone in the channel. For private notes, use a per-person identity such as `user_id=f"slack-{team_id}-{user_id}"`. Tex user ids should use only `[A-Za-z0-9_-]`.
- **Active vs deep.** `mode="active"` only covers conversations with writes within the inactivity window (30 minutes by default). Older channel history is in long-term memory and needs `mode="deep"`.
- **Skip noisy messages.** Filter joins, leaves, uploads and reactions before `remember`. That saves tokens and reduces recall noise.
- **Acknowledge slow recalls.** Add a `:thinking_face:` reaction right away, then post the answer, especially for `mode="deep"`.
- **Real timestamps.** Use the Slack `ts`, not "now", so backfilled history keeps its dates. Replaying the same message (same channel, timestamp and text) doesn't duplicate active-tier fragments, but it is billed again.
