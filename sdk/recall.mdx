---
title: "Recall"
description: "Pull the most relevant slice of memory for a query."
---

```python
tex.recall(
    q: str,
    *,
    session_id: str,
    mode: Literal["active", "deep"] = "active",
    top_k: int | None = None,
    include_timeline: bool = False,
    scope: str | None = None,
) -> RecallResponse
```

<Tip>
  **When to use:** before the agent answers — it's the agent's read path. Use `mode="active"` for every turn and `mode="deep"` for older history and documents. For search or list screens, use [`search`](/sdk/search). See [Choosing an API](/concepts/choosing-apis).
</Tip>

<Note>
  `recall` is callable on the client itself: `tex.recall(...)`. It calls `POST /recall`.
</Note>

## Parameters

<ParamField path="q" type="str" required>
  Natural-language query. The user's most recent message works well.
</ParamField>

<ParamField path="session_id" type="str" required>
  The current session. Required by the SDK, but it does **not** filter results — recall reads across all of your episodes and visible scopes.
</ParamField>

<ParamField path="mode" type='"active" | "deep"' default='"active"'>
  `active` searches the active tier (open episodes). `deep` also searches the long-term store and runs a second pass. See [Recall and ranking](/concepts/retrieval).
</ParamField>

<ParamField path="top_k" type="int | None">
  Number of hits across kinds. Defaults to **15** (`active`) / **25** (`deep`). The API accepts 1–50 and caps the effective value at **30**.
</ParamField>

<ParamField path="include_timeline" type="bool" default="false">
  Adds a pre-rendered chronological summary string.
</ParamField>

<ParamField path="scope" type="str | None">
  Narrow the read to one visible scope, e.g. `"team:fpa-pod"`. Omit to read every scope you can see. `403 scope_not_visible` if you are not a member. The client's `default_scope` does not apply to reads.
</ParamField>

## Returns

<ResponseField name="hits.turns" type="list[RecallHit]">
  Conversation turns most relevant to `q`.
</ResponseField>

<ResponseField name="hits.observations" type="list[RecallHit]">
  Observations attached to past turns.
</ResponseField>

<ResponseField name="hits.entities" type="list[RecallEntity]">
  Reserved for linked entities. Currently always empty.
</ResponseField>

<ResponseField name="confidence" type="float">
  In [0, 1], derived from the top reranker score. A relative signal, not a calibrated probability.
</ResponseField>

<ResponseField name="timeline" type="str | None">
  Chronological summary. Set only when `include_timeline=True`.
</ResponseField>

<ResponseField name="mode" type="str">
  Echoes the request mode.
</ResponseField>

<ResponseField name="usage" type="Usage | None">
  `tokens_in` / `tokens_out` billed for this call.
</ResponseField>

<ResponseField name="raw" type="dict">
  The full response body. Also exposed as `resp.active_tier_error` (SDK 1.2.2+), set when the active tier failed and hits came only from the remaining tier.
</ResponseField>

### `RecallHit` (turns / observations)

```python
@dataclass(frozen=True)
class RecallHit:
    id: str | None
    text: str           # includes date and role, e.g. "[Date: …] [user] …"
    score: float        # ranking score
    kind: str           # "turn" | "observation"
    timestamp: str | None
    raw: dict
```

### `RecallEntity`

```python
@dataclass(frozen=True)
class RecallEntity:
    id: str | None
    label: str
    score: float
    raw: dict
```

## Examples

### Build a chatbot system prompt

```python
def respond(user_msg: str, sid: str) -> str:
    resp = tex.recall(q=user_msg, session_id=sid, top_k=5)
    memory = "\n".join(f"- {h.text}" for h in resp.hits.turns)

    return llm.complete([
        {"role": "system", "content": f"Relevant memory:\n{memory}"},
        {"role": "user",   "content": user_msg},
    ])
```

### Fall back to deep

```python
resp = tex.recall(q=q, session_id=sid)

if not resp.hits.turns or resp.confidence < 0.3:   # tune on your data
    resp = tex.recall(q=q, session_id=sid, mode="deep")
```

### Team-only read

```python
resp = tex.recall(q="open items for the budget cycle",
                  session_id=sid, scope="project:budget-cycle-2027")
```

### Temporal queries

```python
resp = tex.recall(
    q="when did we discuss pricing?",
    session_id=sid,
    include_timeline=True,
)

if resp.timeline:
    print(resp.timeline)
```

## Latency

`active` is the fast path for interactive calls. `deep` searches more and runs a second pass, so it is slower. Bound tail latency on interactive paths with a lower `timeout` and degrade gracefully:

```python
from tex import APITimeoutError

try:
    resp = tex.recall(q=q, session_id=sid)
    context = "\n".join(h.text for h in resp.hits.turns)
except APITimeoutError:
    context = "(no memory available)"
```
