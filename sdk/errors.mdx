All Tex exceptions inherit from `tex.TexError`.

| Class | Status | Inherits | When |
| --- | --- | --- | --- |
| `InvalidScopeError` | — | `TexError`, `ValueError` | Malformed scope id, raised before any request |
| `InvalidInactivityTimeoutError` | — | `TexError`, `ValueError` | SDK 1.2.1+: inactivity window not an `int` in 300–86,400, raised before any request |
| `BadRequestError` | 400 | `APIStatusError` | Malformed payload on `/v3` / `/v4` routes |
| `AuthenticationError` | 401 | `APIStatusError` | Bad key, expired or invalid token |
| `PermissionDeniedError` | 403 | `APIStatusError` | Scope not visible, `containerTag` not permitted, key lacks impersonation scope, admin-only route |
| `NotFoundError` | 404 | `APIStatusError` | Unknown resource, or a document you can't see |
| `ConflictError` | 409 | `APIStatusError` | Update/delete of a pipeline document; duplicate `org_id` on signup |
| `UnprocessableEntityError` | 422 | `APIStatusError` | Validation failure on Tex-native routes (e.g. missing turn `timestamp`) |
| `RateLimitError` | 429 | `APIStatusError` | Daily token quota exceeded |
| `InternalServerError` | 5xx | `APIStatusError` | Server error; the SDK already retried |
| `APIStatusError` | other | `APIError` | Any other HTTP error status |
| `APITimeoutError` | — | `APIConnectionError` | Request timed out |
| `APIConnectionError` | — | `APIError` | DNS, TLS, connection reset |
| `APIResponseValidationError` | — | `APIError` | Reserved |

`TexHTTPError` (alias of `APIStatusError`) and `TexAuthError` (alias of `AuthenticationError`) are kept for backward compatibility.

## Attributes

```python
e.message         # str — see "Reading the error code" below
e.status_code     # int          (APIStatusError subclasses)
e.request_id      # str | None   X-Correlation-ID response header — quote in tickets
e.details         # the parsed JSON response body (dict), when there is one
e.response_text   # raw response body, capped at 2,000 chars
```

<Warning>
  `APITimeoutError` and `APIConnectionError` are **network errors** — no response, so no `status_code`, `request_id`, `details`, or `response_text`. `InvalidScopeError` and `InvalidInactivityTimeoutError` are raised client-side and have only a message.
</Warning>

## Reading the error code

Tex returns two error body shapes:

<Tabs>
  <Tab title="Tex-native routes">
    `/recall`, `/ingestion/*`, `/auth/*`, `/me/*`, `/usage/*`, `/admin/*`:

    ```json
    {
      "error": "HTTP 403",
      "message": "Write scope 'team:finance' is not in your visible scopes. …",
      "details": {
        "error": "scope_not_visible",
        "scope": "team:finance",
        "message": "…",
        "visible_scopes": ["org:acme", "team:fpa-pod", "user:alice"]
      },
      "timestamp": "2026-09-14T10:00:00Z",
      "request_id": null
    }
    ```

    The SDK uses the top-level `error` field as `e.message`, so `e.message == "HTTP 403"`. The machine-readable code is `e.details["details"]["error"]`. Request validation errors (`422`) use FastAPI's shape: `{"detail": [{"loc": [...], "msg": "...", ...}]}`.
  </Tab>
  <Tab title="Supermemory-compatible routes">
    `/v3/*`, `/v4/*`:

    ```json
    {
      "error": "container_tag_not_permitted",
      "containerTag": "bob",
      "message": "This token is bound to a single user; …"
    }
    ```

    `e.message` is the code and `e.details["error"]` holds it too. Validation errors on these routes are `400` with `{"error": "BadRequest", "details": "…"}`.
  </Tab>
</Tabs>

A helper that works for both:

```python
def tex_error_code(e) -> str | None:
    d = e.details if isinstance(e.details, dict) else {}
    inner = d.get("details")
    return (inner if isinstance(inner, dict) else d).get("error")
```

## Error codes you should handle

| Status | Code | Meaning | Fix |
| --- | --- | --- | --- |
| 401 | — | Invalid key, or expired / invalid token | Check the key; for broker-issued tokens, fetch a new one |
| 403 | `scope_not_visible` | Write or narrowed read into a scope you aren't a member of | Grant the membership, wait for the next token refresh, retry |
| 403 | `container_tag_not_permitted` | Per-user token named another user in `containerTag` | Omit `container_tag` or pass your own user id |
| 403 | — (`user_id override not permitted`) | Token exchange with `user_id` using a key without an impersonation scope | Use a key with `impersonate_user` |
| 404 | `NotFound` | Document doesn't exist or isn't visible to you | Check the id and the document's scope |
| 409 | `Conflict` | `documents.update` / `delete` on a `doc-…` id | Add a new document, or edit individual memories |
| 422 | — | Validation (e.g. turn without `timestamp`, `role` not `user`/`assistant`, `org_id` `null`, `inactivity_timeout_seconds` outside 300–86,400) | Fix the payload; pass `org_id` to `Tex(...)` |
| 429 | `quota_exceeded` | Daily token quota (`details.kind`: `tokens_in_daily` / `tokens_out_daily`) | Degrade; resets 00:00 UTC |

## Examples

```python
from tex import (Tex, RateLimitError, AuthenticationError, APITimeoutError,
                 PermissionDeniedError, UnprocessableEntityError)

try:
    tex.conversations.remember(turns, session_id=sid, scope="team:finance")
except PermissionDeniedError as e:
    if tex_error_code(e) == "scope_not_visible":
        log.warning("not a member; visible=%s", e.details["details"]["visible_scopes"])
    raise
except UnprocessableEntityError as e:
    log.warning("bad payload: %s", e.details)   # {"detail": [{"loc": [...], ...}]}
    raise
except RateLimitError:
    enqueue_for_tomorrow(turns)
except APITimeoutError:
    enqueue_for_retry(turns)
```

### `AuthenticationError`

Status 401. When the request carried a token, the SDK already tried one refresh (refresh token, or re-exchange of the API key) before raising.

### `RateLimitError`

Status 429. The SDK retries 429 like other transient codes, so by the time you see it, retries are exhausted. Daily-quota 429s won't clear until 00:00 UTC — set `max_retries=0` on paths where you'd rather fail fast.

```python
e.details["details"]
# {"error": "quota_exceeded", "kind": "tokens_in_daily", "used": 1000123,
#  "limit": 1000000, "period": "day_utc", "period_start": "2026-09-14T00:00:00+00:00", "message": "…"}
```

### `InternalServerError`

Status 5xx. The SDK already retried (default 2x). If you still see it, file a ticket with `e.request_id`.

## Built-in retries

The SDK retries automatically on:

- Status codes `408`, `429`, `500`, `502`, `503`, `504`
- Timeouts and network errors

Default: **2 retries** with exponential backoff (0.5s, 1s). `Retry-After` is honored when larger. Override:

```python
tex = Tex(api_key=..., base_url=..., org_id=..., max_retries=5)
```

## Retry safety

| Call | Safe to retry? |
| --- | --- |
| `recall`, `usage.*`, `documents.get`, `search.*` | Yes — reads |
| `conversations.remember` | Mostly — identical turns don't duplicate active fragments, but long-term writes and token metering aren't deduplicated |
| `documents.add`, `memories.add`, `batch_add` | No — each call creates new ids. Record returned ids and reconcile before re-sending |
