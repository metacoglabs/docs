---
title: "Track usage"
description: "Read your org's token totals."
---

```python
tex.usage.today()                    # today's usage + daily quota
tex.usage.summary()                  # current calendar month
tex.usage.summary(month="2026-03")   # specific month
```

The org comes from the token — no `org_id` argument. These calls are not metered and don't count against your quota.

## `tex.usage.today()` → `UsageQuotaStatus`

<ResponseField name="tokens_in_used" type="int">
  Tokens you've sent today (UTC day), across the org.
</ResponseField>

<ResponseField name="tokens_out_used" type="int">
  Tokens returned to the org today.
</ResponseField>

<ResponseField name="tokens_in_limit" type="int">
  Daily ingress cap. `1_000_000` by default.
</ResponseField>

<ResponseField name="tokens_out_limit" type="int">
  Daily egress cap. `5_000_000` by default.
</ResponseField>

<ResponseField name="period" type="str">
  `"day_utc"`.
</ResponseField>

<ResponseField name="period_start" type="str">
  ISO 8601 timestamp at 00:00 UTC today.
</ResponseField>

<ResponseField name="period_end" type="str">
  ISO 8601 timestamp at 00:00 UTC tomorrow.
</ResponseField>

```python
status = tex.usage.today()
print(f"in:  {status.tokens_in_used:,} / {status.tokens_in_limit:,}")
print(f"out: {status.tokens_out_used:,} / {status.tokens_out_limit:,}")
print(f"resets at: {status.period_end}")
```

## `tex.usage.summary(month=None)` → `UsageWindow`

Calendar-month rollup, UTC.

<ParamField path="month" type="str | None">
  `"YYYY-MM"`. Omitted = current month.
</ParamField>

<ResponseField name="period" type="str">
  `"month"`.
</ResponseField>

<ResponseField name="start" type="str">
  ISO 8601 timestamp of the first moment of the month.
</ResponseField>

<ResponseField name="end" type="str">
  ISO 8601 timestamp of the first moment of the next month.
</ResponseField>

<ResponseField name="tokens_in" type="int">
  Total ingress tokens for the month.
</ResponseField>

<ResponseField name="tokens_out" type="int">
  Total egress tokens for the month.
</ResponseField>

```python
months = ["2026-04", "2026-05", "2026-06", "2026-07", "2026-08", "2026-09"]
rows = [
    {"month": m, "tokens_in": w.tokens_in, "tokens_out": w.tokens_out}
    for m in months
    for w in [tex.usage.summary(month=m)]
]
```

## Patterns

- **Per-response usage** is on every `remember` / `recall`:

  ```python
  resp = tex.recall(q="...", session_id=sid)
  print(resp.usage.tokens_in, resp.usage.tokens_out)
  ```

- **Quota-aware routing** — gate non-essential paths past 90%:

  ```python
  status = tex.usage.today()
  if status.tokens_in_used > 0.9 * status.tokens_in_limit:
      return generate_without_memory(query)
  ```

  Cache `usage.today()` on your side (≤ 60s) — this is soft gating, not strict.
