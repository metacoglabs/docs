---
title: "Remember"
description: "Persist conversation turns to memory."
---

```python
tex.conversations.remember(
    turns: list[dict],
    *,
    session_id: str,
    metadata: dict | None = None,
    scope: str | None = None,
    inactivity_timeout_seconds: int | None = None,   # 1.2.1+
) -> RememberResponse
```

<Tip>
  **When to use:** for the ongoing conversation — every user message and agent reply. Recallable immediately; summarised into long-term memory after the conversation goes idle. For facts someone asked to keep, use [`memories.add`](/sdk/memories); for files, [`documents.add`](/sdk/documents). See [Choosing an API](/concepts/choosing-apis).
</Tip>

Calls `POST /ingestion/memory`.

## Parameters

<ParamField path="turns" type="list[dict]" required>
  At least one turn (an empty list returns `422`). Each turn:

  ```python
  {
    "role": "user",                          # "user" or "assistant" only
    "text": "the thing said",                # non-empty
    "timestamp": "2026-09-14T14:00:00Z",     # required, ISO 8601 string
    "observations": ["short fact", "..."],   # optional list of strings
  }
  ```

  A missing `timestamp`, an empty `text`, or any other `role` (such as `"system"`) returns `422` (`UnprocessableEntityError`).
</ParamField>

<ParamField path="session_id" type="str" required>
  The conversation, work session, or task this batch belongs to. Turns with the same `session_id` form one episode. It does not limit who can read them — see [scopes](/concepts/scopes).
</ParamField>

<ParamField path="metadata" type="dict | None">
  Free-form metadata. Accepted but currently unused.
</ParamField>

<ParamField path="scope" type="str | None">
  Hierarchical write scope, e.g. `"team:fpa-pod"`. Falls back to the client's `default_scope`, then to your personal `user:<user_id>` scope. `403 scope_not_visible` if you are not a member. Malformed ids raise `InvalidScopeError` before any request.
</ParamField>

<ParamField path="inactivity_timeout_seconds" type="int | None">
  **SDK 1.2.1+.** How long this conversation's episode may sit idle before it closes and consolidates, 300–86,400 seconds. Falls back to the client's `active_inactivity_timeout_seconds`, then your org default, then 30 minutes. The episode keeps the last window it was given. Out-of-range or non-integer values raise `InvalidInactivityTimeoutError` before any request. See [Inactivity window](/concepts/memory-model#inactivity-window).
</ParamField>

## Returns

<ResponseField name="job_id" type="str | None">
  Per-call id for correlating with logs.
</ResponseField>

<ResponseField name="active_fragment_ids" type="list[str]">
  Active-tier fragment ids, in order: each turn, then its observations. Recallable immediately.
</ResponseField>

<ResponseField name="passive_job_id" type="str | None">
  Reserved. Currently always `None`.
</ResponseField>

<ResponseField name="usage" type="Usage | None">
  `tokens_in` / `tokens_out` for this call. `tokens_out` is 0 on `remember`.
</ResponseField>

<ResponseField name="raw" type="dict">
  The full response body.
</ResponseField>

## Examples

### Single user turn

```python
tex.conversations.remember(
    session_id="chat-1",
    turns=[
        {
            "role": "user",
            "text": "I prefer Python over JavaScript.",
            "timestamp": "2026-09-14T10:00:00Z",
        },
    ],
)
```

### Both sides of a turn

```python
from datetime import datetime, timezone

def now_iso() -> str:
    return datetime.now(timezone.utc).isoformat().replace("+00:00", "Z")

tex.conversations.remember(
    session_id="chat-1",
    turns=[
        {"role": "user",      "text": user_msg,      "timestamp": now_iso()},
        {"role": "assistant", "text": assistant_msg, "timestamp": now_iso()},
    ],
)
```

### Share with a team

```python
tex.conversations.remember(
    session_id="q3-variance-review",
    scope="team:fpa-pod",
    turns=[{"role": "user", "text": "Travel spend is 12% over plan in EMEA.",
            "timestamp": now_iso()}],
)
```

### Long working session

```python
# SDK 1.2.1+: keep a model-review session in the active tier through 2-hour breaks
tex.conversations.remember(turns, session_id="fy27-model-review",
                           inactivity_timeout_seconds=7200)
```

### Backfill historical conversation

```python
turns = [
    {"role": t["role"], "text": t["text"], "timestamp": t["ts"]}
    for t in db.fetch_chat_history(conv_id)
]

# One batch instead of per-turn calls
tex.conversations.remember(turns, session_id=f"chat-{conv_id}")
```

### Observations

Pass short facts you extracted yourself. Tex stores them next to the turn; it doesn't extract observations on this path.

```python
turns = [{
    "role": "user",
    "text": "I'm allergic to shellfish.",
    "timestamp": "2026-09-14T10:00:00Z",
    "observations": ["avoids shellfish"],
}]

tex.conversations.remember(turns, session_id="chat-1")
```

## Behavior

<Steps>
  <Step title="Synchronous write">
    The call returns `202` after the turns are written to the active tier. They are recallable immediately with `recall(mode="active")`.
  </Step>
  <Step title="Episode close and consolidation">
    Once the session goes without writes for its inactivity window (30 minutes by default), the episode closes and is consolidated into the long-term store. From then on, find it with `recall(mode="deep")`. See [How memory works](/concepts/memory-model#inactivity-window).
  </Step>
</Steps>

## Best practices

- **Batch.** Pass many turns in one call.
- **UTC ISO 8601** timestamps (`...Z`). Use the time the turn happened, not the time you send it.
- **Skip system prompts and filler.** They consume tokens and add noise.
- **Don't block the user.** Push `remember` to a background task.

## Retries and duplicates

The active-tier fragment id is derived from the write scope, org, user, session, timestamp, and text. Replaying an identical turn does **not** create a duplicate active fragment.

The long-term write and token metering are **not** deduplicated. Keep the original timestamp when you retry, and avoid replaying batches that already succeeded.
