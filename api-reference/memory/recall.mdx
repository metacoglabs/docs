---
title: "Recall memory"
description: "Retrieve the most relevant slice of memory."
api: "POST https://api.getmetacognition.com/recall"
---

REST equivalent of `tex.recall(...)`.

## Headers

```http
Authorization: Bearer <access_token>
Content-Type: application/json
```

## Body

<Tabs>
  <Tab title="All visible scopes">
    ```json
    {
      "scope": {"org_id": "acme", "session_id": "chat-1"},
      "q": "what does the user prefer?",
      "mode": "active",
      "top_k": 5
    }
    ```
  </Tab>
  <Tab title="One scope">
    ```json
    {
      "scope": "team:fpa-pod",
      "session_id": "chat-1",
      "q": "open items from the variance review",
      "mode": "deep"
    }
    ```
  </Tab>
</Tabs>

<ParamField body="scope" type="string | object" required>
  Either:

  - **A tenant object** `{org_id, user_id?, session_id?}` — reads **every** scope visible to the token's user. `org_id` is required (≥ 1 char); identity comes from the token.
  - **A scope id string** `"<kind>:<value>"` — narrows the read to that one scope. `403 scope_not_visible` if it isn't visible to you.
</ParamField>

<ParamField body="session_id" type="string">
  Session for the string-scope form. It does not filter results.
</ParamField>

<ParamField body="q" type="string" required>
  Natural-language query (≥ 1 char).
</ParamField>

<ParamField body="mode" type='"active" | "deep"' default='"active"'>
  `active` searches the active tier. `deep` also searches the long-term store and runs a second pass. See [retrieval](/concepts/retrieval).
</ParamField>

<ParamField body="top_k" type="integer">
  Hits across kinds. Defaults to **15** (active) / **25** (deep). Accepts 1–50; values above 30 are clamped to 30.
</ParamField>

<ParamField body="include_timeline" type="boolean" default="false">
  Attach a chronological summary string.
</ParamField>

<ParamField body="agent_id" type="string">
  Agent whose active episodes to search. Defaults to `default-agent`, matching `/ingestion/memory`.
</ParamField>

## Response — `200`

<ResponseField name="hits.turns" type="array">
  Ranked turns: `{id, text, score, kind, timestamp}`.
</ResponseField>

<ResponseField name="hits.observations" type="array">
  Ranked observations, same shape.
</ResponseField>

<ResponseField name="hits.entities" type="array">
  `{id, label, score}`. Currently always empty.
</ResponseField>

<ResponseField name="confidence" type="number">
  In [0, 1], from the top reranker score. Relative, not calibrated.
</ResponseField>

<ResponseField name="timeline" type="string | null">
  Set only when `include_timeline=true`.
</ResponseField>

<ResponseField name="mode" type="string">
  Echoes the request mode.
</ResponseField>

<ResponseField name="usage" type="object">
  `{tokens_in, tokens_out}` for this call.
</ResponseField>

<ResponseField name="active_tier_error" type="string | null">
  Set when the active tier failed during this call. Hits then come only from the remaining tier.
</ResponseField>

## Errors

| Status | When |
| --- | --- |
| `401` | Missing, invalid, or expired token |
| `403` | `scope_not_visible` — the scope string isn't one of your visible scopes |
| `422` | Validation — empty `q`, invalid `mode`, `top_k` outside 1–50, malformed scope, `org_id` missing or `null` |
| `429` | `quota_exceeded` |

## Example

<CodeGroup>
```bash cURL
curl -X POST https://api.getmetacognition.com/recall \
  -H "Authorization: Bearer $JWT" \
  -H 'content-type: application/json' \
  -d '{
    "scope": {"org_id":"acme","session_id":"chat-1"},
    "q": "any food restrictions?",
    "top_k": 3
  }'
```

```python Python
import httpx

resp = httpx.post(
    "https://api.getmetacognition.com/recall",
    headers={"Authorization": f"Bearer {jwt}"},
    json={
        "scope": {"org_id": "acme", "session_id": "chat-1"},
        "q": "any food restrictions?",
        "top_k": 3,
    },
    timeout=30,
)
data = resp.json()
for t in data["hits"]["turns"]:
    print(f"[{t['score']:.2f}] {t['text']}")
```
</CodeGroup>
