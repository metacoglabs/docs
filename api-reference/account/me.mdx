---
title: "Current org"
description: "Read the org and user bound to your token, and the API keys you may see."
api: "GET https://api.getmetacognition.com/me"
---

Returns the org and user bound to the access token, plus API key metadata.

## Headers

```http
Authorization: Bearer <access_token>
```

## Response — `200`

<ResponseField name="org_id" type="string">
  The org bound to the token.
</ResponseField>

<ResponseField name="user_id" type="string">
  The user bound to the token — `apikey_<id prefix>` for a key's own identity, or the end user for a per-user token.
</ResponseField>

<ResponseField name="api_keys" type="array">
  API key metadata, newest first. No plaintext.

  - **Org admin** — a token exchanged without `user_id` from a key with `admin` or `*`: every key in the org.
  - **Any other token exchanged without `user_id`**: only the key it was exchanged from.
  - **Per-user tokens**: an empty list.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl -H "Authorization: Bearer $JWT" \
  https://api.getmetacognition.com/me
```

```python Python
import httpx

resp = httpx.get(
    "https://api.getmetacognition.com/me",
    headers={"Authorization": f"Bearer {access_token}"},
    timeout=10,
)
me = resp.json()
print(me["org_id"], me["user_id"], len(me["api_keys"]), "keys")
```

## When to use

- Show "signed in as…" in your own tooling.
- Confirm which org and user a token belongs to.
- Audit active keys before a rotation (org admin).
