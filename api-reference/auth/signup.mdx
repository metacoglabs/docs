---
title: "Create account"
description: "Create a new org and mint its first API key."
api: "POST https://api.getmetacognition.com/signup"
---

Creates a new organization and its first API key. The plaintext API key appears in the response **once and only once**.

## Body

```json
{
  "org_id": "acme",
  "name": "acme production"
}
```

<ParamField body="org_id" type="string">
  Optional org id. Auto-generated as `org_<random>` when omitted. Letters, digits, `-`, and `_` only; ≤ 64 chars. `409 Conflict` if it already exists.
</ParamField>

<ParamField body="name" type="string">
  Label for the first API key. Optional, ≤ 64 chars.
</ParamField>

## Response — `201`

<ResponseField name="org_id" type="string">
  The org id. Pass it to the SDK as `org_id`.
</ResponseField>

<ResponseField name="user_id" type="string">
  A generated id (`user_<random>`). Nothing is bound to it; choose your own user ids for per-user clients.
</ResponseField>

<ResponseField name="api_key" type="string">
  The plaintext API key (`tex_live_…`). **Save it now — there's no recovery.**
</ResponseField>

<ResponseField name="key" type="object">
  Key metadata: `id`, `prefix`, `display_id`, `name`, `scopes` (`["*"]`), `is_active`, `created_at`, `last_used_at`, `revoked_at`.
</ResponseField>

The first key has scopes `["*"]`: it can mint per-user tokens and manage the org's keys. Treat it as an owner credential.

## Example

<CodeGroup>
```bash cURL
curl -X POST https://api.getmetacognition.com/signup \
  -H 'content-type: application/json' \
  -d '{"name": "acme production"}'
```

```python Python
import httpx

resp = httpx.post(
    "https://api.getmetacognition.com/signup",
    json={"name": "acme production"},
    timeout=10,
)
data = resp.json()
api_key = data["api_key"]   # store this securely
org_id = data["org_id"]
```

<Note>

## Errors

| Status | When |
| --- | --- |
| `409 Conflict` | The `org_id` you supplied is already in use. |
| `422 Unprocessable Entity` | `org_id` or `name` failed validation. |
