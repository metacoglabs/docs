The Tex API is a small REST surface. If you're writing Python, prefer the [SDK](/sdk/installation) — it handles auth, refresh, and serialization. Use the raw API from other languages, from on-device apps holding a broker-issued token, or from a sidecar.

## Base URL

```
https://api.getmetacognition.com
```

HTTPS only.

## Auth

Tex-native endpoints (`/recall`, `/ingestion/*`, `/me/*`, `/usage/*`, `/admin/*`) expect a JWT access token:

```http
Authorization: Bearer <access_token>
```

Get one from [`POST /auth/token-exchange`](/api-reference/auth/token-exchange) — for the key's own identity, or for a specific end user with `user_id`.

The Supermemory-compatible endpoints (`/v3/*`, `/v4/*`) accept **either** a raw API key or an access token as the Bearer credential:

| Credential | Identity | `containerTag` |
| --- | --- | --- |
| Raw API key | The key's identity; `containerTag` selects the end user | Any user in the org |
| Per-user access token | The token's user | Omit, or the user's own id (else `403 container_tag_not_permitted`) |

## Content type

```http
Content-Type: application/json
```

## Correlation ID

Send an `X-Correlation-ID` header, or the server generates one. It is returned on every response. Quote it in support tickets.

```http
X-Correlation-ID: 4f1d8e3c-2a9b-4c0d-9e6f-1a2b3c4d5e6f
```

## Status codes

| Status | Meaning |
| --- | --- |
| `200` | OK |
| `201` | Created (signup, key creation, new membership) |
| `202` | Accepted (`/ingestion/memory`) |
| `204` | No content (key revoke, v3 document delete) |
| `400` | Bad payload (`/v3`, `/v4` validation) |
| `401` | Missing, invalid, or expired credential |
| `403` | Forbidden — scope not visible, `containerTag` not permitted, missing role |
| `404` | Not found (or not visible to you) |
| `409` | Conflict — duplicate org id, pipeline document update/delete |
| `422` | Validation error on Tex-native routes |
| `429` | Daily token quota exceeded |
| `5xx` | Server error |

## Error bodies

Tex-native routes:

```json
{
  "error": "HTTP 403",
  "message": "Write scope 'team:finance' is not in your visible scopes. …",
  "details": {"error": "scope_not_visible", "scope": "team:finance", "message": "…", "visible_scopes": ["org:acme", "user:alice"]},
  "timestamp": "2026-09-14T10:00:00Z",
  "request_id": null
}
```

`details` is `null` for plain errors. Request validation errors (`422`) use FastAPI's shape instead:

```json
{"detail": [{"type": "missing", "loc": ["body", "turns", 0, "timestamp"], "msg": "Field required", "input": {…}}]}
```

Supermemory-compatible routes:

```json
{"error": "NotFound", "details": "Document not found"}
```

## Limits

- Daily quota per org: `tokens_in` 1,000,000 and `tokens_out` 5,000,000, reset 00:00 UTC. Only `/ingestion/memory` and `/recall` are metered. See [Usage and billing](/concepts/usage-billing).
- Request body: 50 MB maximum.
- No per-minute rate limit is enforced today.

## Retries

Retry `408`, `500`, `502`, `503`, `504`, and network errors with exponential backoff, honoring `Retry-After`. Don't retry `400`, `401`, `403`, `404`, `409`, `422`. A quota `429` won't clear until 00:00 UTC.

Retrying writes is not always free — see [retry safety](/sdk/errors#retry-safety).
