Tex sits between your agent loop and your LLM. Stream conversation turns to it; pull back the relevant slice on every new request. Bounded prompts, cross-session continuity, no Redis to babysit.

## The loop

<Steps>
  <Step title="Remember">
    ```python
    tex.conversations.remember(session_id="chat-1", turns=[
      {"role": "user", "text": "I'm allergic to shellfish.", "timestamp": "..."},
    ])
    ```
  </Step>
  <Step title="Recall">
    ```python
    hits = tex.recall(q=user_msg, session_id="chat-1")
    context = "\n".join(h.text for h in hits.hits.turns)
    ```
  </Step>
  <Step title="Generate">
    Drop `context` into your system prompt. Reply. Persist the new turns. Loop.
  </Step>
</Steps>
