## The loop

<Steps>
  <Step title="Remember">
    ```python
    tex.conversations.remember(session_id="chat-1", turns=[
        {"role": "user", "text": "I'm allergic to shellfish.",
         "timestamp": "2026-09-14T10:00:00Z"},
    ])
    ```
  </Step>
  <Step title="Recall">
    ```python
    resp = tex.recall(q=user_msg, session_id="chat-1")
    context = "\n".join(h.text for h in resp.hits.turns)
    ```
  </Step>
  <Step title="Generate">
    Drop `context` into your system prompt. Reply. Persist the new turns. Loop. Save lasting facts with `memories.add` and files with `documents.add` — see [Choosing an API](/concepts/choosing-apis).
  </Step>
</Steps>
