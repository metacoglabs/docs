## LoCoMo

LoCoMo evaluates long-conversation memory across 10 multi-session conversations with **1,984 questions** in 5 categories: single-hop retrieval, multi-hop reasoning, temporal reasoning, open-domain inference, and adversarial abstention.

### Protocol

<Note>
  **96.07% is the best merged score over iterative retry rounds**, not a single pass.

  1. **Initial pass** over all 1,984 questions: 86.34%.
  2. **Retry rounds.** Each round re-asks only the questions judged wrong so far; verdicts for questions already judged correct are carried forward.
  3. After three retry rounds the merged result is **1,906 / 1,984 = 96.07%**.
</Note>

| Setting | Value |
| --- | --- |
| System | Tex full system (active tier + long-term store and knowledge graph), running on the production deployment |
| Dataset | LoCoMo, all 10 conversations, 1,984 QA pairs |
| Reader | gpt-5.2, reasoning effort medium |
| Judge | gpt-4o, LLM-as-judge, binary correct / incorrect |
| Score | Judge accuracy, best merged result over iterative retry rounds (above) |
| Date | September 2026 |

### Rounds

| Round | Questions asked | Overall |
| --- | --- | --- |
| Initial pass | 1,984 | 86.34% |
| Retry 1 | previously wrong only | 92.19% |
| Retry 2 | previously wrong only | 93.70% |
| Retry 3 | previously wrong only | **96.07%** |

### Ablation — what each capability contributed

From the same April 2026 report, peeling layers off the retrieval pipeline on LongMemEval_S:

| Capability | What it does | Δ accuracy |
| --- | --- | --- |
| Adaptive retrieval | Adjusts retrieval depth + strategy per query type | +3.6% |
| Query understanding | LLM-free semantic expansion | +1.9% |
| Multi-stage relevance scoring | Progressive filter + rerank | +2.4% |
| Structured reasoning | Enumerate / count across fragments | +3.1% |
| Temporal awareness | Resolve relative dates, build chronology | +3.0% |
| Combined pipeline | Everything working together | +1.6% |
| | **Base → Full System** | **76.6% → 92.2%** |

## Methodology

- **Evaluation:** LLM-as-judge with category-specific judge prompts, binary verdicts, averaged per category.
- **LoCoMo (September 2026):** 10 conversations, 1,984 QA pairs, Tex full system on production; reader gpt-5.2 (reasoning effort medium); judge gpt-4o; best merged score over iterative retry rounds as described in [Protocol](#protocol).
- **LongMemEval_S (April 2026):** 500 questions, ~48 sessions each, Tex active tier.
- Competitor numbers are taken from the cited publications and were not reproduced by us.
