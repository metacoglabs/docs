title: "Quickstart"
description: "First call in five minutes."
---

<Steps>
  <Step title="Get an API key">
    Sign up at [the Tex dashboard](https://tex-dashboard-ashen.vercel.app/signup) and copy the key and your **org id**.

    <Warning>
      The key appears only once — store it now. Keep it on your server; never ship it in a mobile, desktop, or browser app.
    </Warning>
  </Step>

  <Step title="Install">
    ```bash
    pip install tex-sdk
    ```

    Or `uv add tex-sdk` / `poetry add tex-sdk`. Requires Python ≥ 3.9. Distribution name is `tex-sdk`; import name is `tex`.
  </Step>

  <Step title="Make your first call">
    ```python first_call.py
    import os
    from tex import Tex

    tex = Tex(
        api_key=os.environ["TEX_API_KEY"],
        base_url="https://api.getmetacognition.com",
        org_id=os.environ["TEX_ORG_ID"],   # recommended — see note
        user_id="alice",                   # the end user this client acts for
    )

    tex.conversations.remember(session_id="chat-1", turns=[
        {"role": "user", "text": "I'm allergic to shellfish.",
         "timestamp": "2026-09-14T14:00:00Z"},
    ])

    resp = tex.recall(q="any food restrictions?", session_id="chat-1")
    for h in resp.hits.turns:
        print(f"[{h.score:.2f}] {h.text}")

    print("confidence:", resp.confidence)
    print("usage:", resp.usage.tokens_in, "in /", resp.usage.tokens_out, "out")
    ```

    ```bash
    export TEX_API_KEY="tex_live_..."
    export TEX_ORG_ID="org_..."
    python first_call.py
    ```
  </Step>
</Steps>

<Note>
  **Why `org_id`?** With `api_key` + `user_id`, the SDK checks that the key belongs to this org, so a wrong key fails fast. SDK 1.2.2 and later fill it in from the token when omitted; **1.2.0 and 1.2.1 require it** — without it, the first `remember` / `recall` sends `org_id: null` and gets `422`.
</Note>

<Note>
  **Why `user_id`?** Memory is isolated per user. With `user_id`, the SDK exchanges your key for a token minted for that user (your key needs an impersonation scope — keys from signup have it). Without `user_id`, every call acts as the key's own identity and all traffic shares one memory. See [Per-user clients](/sdk/per-user-clients).
</Note>

<Tip>
  Every turn needs `role` (`"user"` or `"assistant"`), non-empty `text`, and an ISO 8601 `timestamp`. A missing timestamp returns `422`.
</Tip>
