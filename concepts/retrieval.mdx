`tex.recall(q, session_id, ...)` is your read path.

## Modes

<CardGroup cols={2}>
  <Card title="active (default)" icon="bolt">
    Single-pass. **1.5–2.5s.** Use for every interactive call.
  </Card>
  <Card title="deep" icon="diagram-project">
    Two-pass with iterative rerank. **3–6s.** For periodic analysis or low-confidence retries.
  </Card>
</CardGroup>

## `top_k`

Defaults: **15** (active) / **25** (deep). Server caps at **30** regardless of what you send.

| Use case | `top_k` |
| --- | --- |
| Live chat, small context | 3–5 |
| Live chat, large context | 8–15 |
| Summaries / digests | 20–30 |

Larger `top_k` = more `tokens_out` billed.

## Confidence

Every recall returns a `confidence ∈ [0, 1]`, calibrated so `P(hits relevant | c) ≈ c`.

| Range | Meaning | Action |
| --- | --- | --- |
| ≥ 0.6 | Strong | Use as-is |
| 0.3 – 0.6 | Useful but uncertain | Use, cite the sources |
| < 0.3 | Weak | Try `mode="deep"`, or skip memory |

```python
hits = tex.recall(q=q, session_id=sid)
if hits.confidence < 0.3:
    hits = tex.recall(q=q, session_id=sid, mode="deep")
```

## What's in a hit

```python
RecallHit(id, text, score, kind, timestamp)        # turns + observations
RecallEntity(id, label, score)                     # entities
```

`hits.hits.turns` is what you stuff into a system prompt. `hits.hits.observations` are atomic facts. `hits.hits.entities` are linked things — useful for analytical queries.

## Timeline

```python
hits = tex.recall(q="when did we discuss pricing?",
                  session_id=sid, include_timeline=True)
print(hits.timeline)   # a pre-rendered chronological summary string
```

`timeline` is an `Optional[str]` — drop it into a prompt as-is. It's not iterable.
