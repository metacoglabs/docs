title: "Users, teams, and scopes"
description: "Personal, team, project, and org memory — how Tex decides who can read and write what."
---

Every memory belongs to a **scope**. A scope id is `"<kind>:<value>"`:

| Kind | Example | Who can see it |
| --- | --- | --- |
| `user` | `user:alice` | Only that user. Every user implicitly has their own. |
| `team` | `team:fpa-pod` | Users granted a membership |
| `project` | `project:budget-cycle-2027` | Users granted a membership |
| `org` | `org:acme` | **Every user in the org** (implicit; the value is your Tex org id) |

## Identity comes first

Scopes are resolved for the **user in the token**. A client built with only an API key acts as the key's own identity, so every caller shares one memory. For multi-user apps, give each end user their own identity:

```python
alice = Tex(api_key=KEY, base_url=BASE, org_id=ORG, user_id="alice")
```

See [Per-user clients](/sdk/per-user-clients).

<Warning>
  `session_id` is not an isolation boundary. It groups turns into an episode (one conversation), but recall reads across every episode and scope the caller can see. Encoding end users into `session_id` on a shared client does **not** separate their memory.
</Warning>

## Visible scopes

A user's **visible scopes** are:

1. `user:<user_id>` — implicit
2. `org:<org_id>` — implicit
3. Every scope granted to them by a membership

Memberships are managed with [`/admin/scope-memberships`](/api-reference/admin/scope-memberships). Changes take effect on the user's next token refresh — allow up to 1 hour.

## Writes

- **Default:** writes land in the caller's personal `user:<user_id>` scope.
- **Per call:** pass `scope="team:fpa-pod"` to `remember`, `documents.add`, `memories.add`, and the other write methods.
- **Per client:** set `default_scope="team:fpa-pod"` on `Tex(...)`. A per-call `scope` wins.
- Writing into a scope you can't see returns `403` with `scope_not_visible` and your `visible_scopes`.

```python
pod = Tex(api_key=KEY, base_url=BASE, org_id=ORG, user_id="alice",
          default_scope="team:fpa-pod")
pod.conversations.remember(turns, session_id="variance-review")          # team:fpa-pod
pod.conversations.remember(turns, session_id="notes", scope="user:alice") # personal
```

## Reads

- **Default:** `recall` and search read every visible scope.
- **Narrow:** `tex.recall(q, session_id=..., scope="project:budget-cycle-2027")` reads only that scope. `403 scope_not_visible` if you are not a member.

## Picking a `session_id`

Free-form string. One per conversation, work session, or task. Reuse it while the conversation continues.

<CardGroup cols={2}>
  <Card title="One conversation" icon="message">
    `chat-{conversation_uuid}`
  </Card>
  <Card title="Per-task agent" icon="robot">
    `agent-{task_id}`
  </Card>
  <Card title="Work session on a document" icon="file">
    `doc-{document_id}-{date}`
  </Card>
  <Card title="Support ticket" icon="ticket">
    `ticket-{ticket_id}`
  </Card>
</CardGroup>

Short ids made of letters, digits, `.`, `_`, and `-` are used as-is; other ids work too (they are hashed internally).
