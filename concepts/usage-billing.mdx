The metered unit is **tokens** — `tokens_in` (text you send) and `tokens_out` (text we return). Counted with `tiktoken cl100k_base`, the same encoding as `text-embedding-3-large`.

## Daily quota

<CardGroup cols={2}>
  <Card title="tokens_in" icon="upload">
    **1,000,000 / day** per org
  </Card>
  <Card title="tokens_out" icon="download">
    **5,000,000 / day** per org
  </Card>
</CardGroup>

The day is UTC and resets at 00:00 UTC. Exceeding either cap returns `429` (`RateLimitError`) with `quota_exceeded`. There is no per-minute rate limit on top of the daily quota today.

## What is metered

| Call | `tokens_in` | `tokens_out` |
| --- | --- | --- |
| `remember` (`/ingestion/memory`) | Turn text + observations | 0 |
| `recall` (`/recall`) | The query | Returned hit text, entity labels, and timeline |

Today only these two endpoints are metered and quota-checked. `/usage/*` reads are free.

Every `remember` and `recall` response carries its own usage:

```python
resp = tex.recall(q="...", session_id=sid)
print(resp.usage.tokens_in, resp.usage.tokens_out)
```

For org-wide totals:

```python
today = tex.usage.today()         # today's usage + daily quota
month = tex.usage.summary()       # current calendar month
march = tex.usage.summary("2026-03")
```

## Cost control

- **Cap `top_k`** — defaults 15 / 25. Cut to 5–8 for live chat.
- **Prefer `mode="active"`** for interactive calls; use `deep` when you need older history.
- **Pre-filter writes** — skip "ok" / "thanks" turns.
- **Batch `remember`** — pass many turns in one call instead of looping.
- **Quota-aware routing** — gate non-essential paths when usage is high.

```python
today = tex.usage.today()
if today.tokens_in_used > 0.9 * today.tokens_in_limit:
    return generate_without_memory(query)
```

## Alerts

Poll `tex.usage.today()` from your own monitoring and alert above your threshold. Server-side alerts are not available yet.
