## Symptom → cause → fix

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| `ValueError: base_url is required` | No `base_url` and no `TEX_BASE_URL` | Pass `base_url="https://api.getmetacognition.com"` |
| `UnprocessableEntityError` on the **first** `remember` / `recall` | Client built without `org_id` on SDK 1.2.0–1.2.1 (sends `org_id: null`) | Upgrade to `tex-sdk>=1.2.2`, or pass `org_id=` to `Tex(...)` |
| `UnprocessableEntityError` naming `timestamp` or `role` | Turn without `timestamp`, or `role` other than `user` / `assistant` | Add an ISO 8601 `timestamp`; map other roles to `user` / `assistant` |
| `AuthenticationError` on first call | Wrong or revoked key, or wrong `base_url` | Check the key and `TEX_BASE_URL` |
| `PermissionDeniedError` mentioning `impersonation-capable scope` | `user_id` with a key lacking `impersonate_user` | Use a key with an impersonation scope |
| `PermissionDeniedError` mentioning `/auth/login` | No API key or token — the SDK tried the dev-only login | Pass `api_key` (with `user_id`) or `access_token` |
| `403` `scope_not_visible` | Writing into, or narrowing a read to, a scope you aren't a member of | Grant the membership; allow up to 1 hour; retry |
| `403` `container_tag_not_permitted` | Per-user client passed another user's `container_tag` | Omit `container_tag` or use the user's own id |
| `InvalidScopeError` | Scope not shaped `<kind>:<value>` with kind `user` / `team` / `org` / `project` | Fix the scope string |
| Users see each other's memory | One key-only client shared across end users | Use [per-user clients](/sdk/per-user-clients) — `session_id` doesn't isolate |
| `recall` misses a conversation from earlier today | The session was idle past its inactivity window (30 minutes by default) and was consolidated out of the active tier | Use `mode="deep"`, or set a longer [inactivity window](/concepts/memory-model#inactivity-window) |
| `InvalidInactivityTimeoutError` / `422` on `inactivity_timeout_seconds` | Window outside 300–86,400 seconds, or not an integer | Use 5 minutes to 24 hours, in whole seconds |
| `recall.confidence` always low | `q` doesn't match stored text well | Rephrase; try `mode="deep"`; raise `top_k` |
| `documents.get` returns `404` right after `add` | Wrong id, or document not visible to this user (different user or scope) | Use the returned `doc-…` id with a client that can see its scope |
| `documents.update` / `delete` raises `ConflictError` | Pipeline documents can't be modified by id | Add a new document |
| `documents.list` doesn't show added documents | `list` returns graph nodes, not pipeline documents | Track `doc-…` ids and use `documents.get` |
| `RateLimitError` mid-day | Daily token quota reached | Wait for 00:00 UTC; reduce `top_k`; pre-filter writes |
| Slow `recall` | `mode="deep"` or large `top_k` | Use `mode="active"` for interactive calls |
| `httpx.RemoteProtocolError` / HTTP/2 issues | Egress proxy strips h2 | `Tex(..., http2=False)` |
| `remember` blocks the user | Awaiting it on the request path | Push to a background worker — see [FastAPI recipe](/recipes/fastapi) |

## Filing a ticket

Include:

1. `e.request_id` from the exception (the `X-Correlation-ID`).
2. The approximate timestamp (UTC).
3. The call (`recall`, `remember`, …), `session_id`, and scope.
4. The SDK version (`tex.__version__`).
5. Redact anything sensitive before sharing.

Email `support@getmetacognition.com` or open an issue on [GitHub](https://github.com/metacoglabs).

## Diagnostics — quick checks

```python
# 1. Auth works?
print(tex.auth.whoami())      # {"org_id": ..., "user_id": ..., "session_id": ..., "roles": [...]}

# 2. Round-trip works?
import time
t0 = time.perf_counter()
tex.recall("ping", session_id="diag")
print(f"recall RTT: {(time.perf_counter() - t0) * 1000:.0f}ms")

# 3. SDK version
import tex as tex_sdk; print(tex_sdk.__version__)
```

Service health, no credentials needed:

```bash
curl https://api.getmetacognition.com/health
```

## Common-but-not-bugs

- **Turns out of order?** Recall ranks by relevance, not chronology. For chronological order, set `include_timeline=True`.
- **Different `session_id`, same results?** By design — `session_id` groups turns into episodes; it doesn't filter recall.
- **`hits.entities` is empty.** Entity results aren't populated yet.
- **A write succeeded but a teammate can't see it.** Check the write's scope — writes default to the author's personal scope.
