LangChain's built-in memory classes (`ConversationBufferMemory`, `ConversationBufferWindowMemory`, `ConversationSummaryMemory`, `ConversationKGMemory`) are **buffers, summarizers, or graphs** that live inside your process. Tex is a **hosted retrieval service.**

The migration moves you from "give the LLM the whole sliding window" to "give the LLM the relevant slice."

## Mapping

| LangChain | Tex equivalent |
| --- | --- |
| `ConversationBufferMemory` | `recall(q, session_id=sid, top_k=20)` — returns the 20 most relevant turns instead of the last N. |
| `ConversationBufferWindowMemory(k=10)` | `recall(q, session_id=sid, top_k=10)` — same `k`, ranked by relevance. |
| `ConversationSummaryMemory` | Idle conversations are consolidated into long-term memory (a summary plus the turns) after their inactivity window (30 minutes by default). Reach them with `recall(..., mode="deep")`. You can also attach your own facts as `observations` on a turn. They come back in `hits.observations`. |
| `ConversationKGMemory` | No direct equivalent in `recall` yet. `hits.entities` is currently always empty. |

<Note>
  Memory is isolated by **Tex identity**, not by `session_id`. `recall` searches all of the caller's conversations. Build one client per end user with `user_id=`. See [Per-user clients](/sdk/per-user-clients).
</Note>

    from langchain.chains import ConversationChain

    chain = ConversationChain(

  <Tab title="Tex retrieval — after">
    ```python
    import os
    from datetime import datetime, timezone

    from langchain_core.prompts import ChatPromptTemplate
    from langchain_openai import ChatOpenAI
    from tex import Tex

    tex = Tex(
        api_key=os.environ["TEX_API_KEY"],
        base_url=os.environ["TEX_BASE_URL"],
        org_id=os.environ["TEX_ORG_ID"],   # required on SDK 1.2.0–1.2.1; recommended on 1.2.2+
        user_id=current_user_id,           # one client per end user
    )
    prompt = ChatPromptTemplate.from_messages([
        ("system", "Relevant memory:\n{memory}"),
        ("user", "{input}"),
    ])
    llm_chain = prompt | ChatOpenAI(model="gpt-4o")


    def now_iso() -> str:
        return datetime.now(timezone.utc).isoformat().replace("+00:00", "Z")


    def chat(user_msg: str, sid: str) -> str:
        hits = tex.recall(user_msg, session_id=sid, top_k=10)
        memory = "\n".join(f"- {h.text}" for h in hits.hits.turns)

        answer = llm_chain.invoke({"memory": memory, "input": user_msg}).content

        tex.conversations.remember(
            [
                {"role": "user", "text": user_msg, "timestamp": now_iso()},
                {"role": "assistant", "text": answer, "timestamp": now_iso()},
            ],
            session_id=sid,
        )
        return answer
    ```

## What you give up

LangChain's memory classes are in-process objects with no network call. With Tex you add:

- A network round-trip on every `remember` and `recall`, so each request gets slower. `mode="deep"` is slower than the default `active`.
- A dependency on the Tex service being available.

What you gain:

- Memory survives restarts and deploys.
- Bounded prompt size, set by `top_k`.
- Continuity across conversations for the same user, over days and weeks. Use `mode="deep"` for conversations idle longer than their inactivity window (30 minutes by default).
- Sharing between users through [scopes](/sdk/scopes) (`team:`, `project:`, `org:`).
- A relevance `confidence` score to gate fallback paths. It is relative, not a calibrated probability.

For a hobby project, LangChain's buffer is fine. For user-facing production apps, Tex's retrieval is usually the better tradeoff.

## Drop-in adapter (optional)

If you have many LangChain chains and don't want to rewrite them, wrap Tex in a `BaseChatMemory` subclass:

```python tex_chat_memory.py
from datetime import datetime, timezone
from typing import Any

from langchain.memory.chat_memory import BaseChatMemory
from tex import Tex


def now_iso() -> str:
    return datetime.now(timezone.utc).isoformat().replace("+00:00", "Z")


class TexChatMemory(BaseChatMemory):
    tex: Any              # a per-user tex.Tex client
    session_id: str
    top_k: int = 10

    @property
    def memory_variables(self) -> list[str]:
        return ["history"]

    def load_memory_variables(self, inputs: dict[str, Any]) -> dict[str, Any]:
        q = inputs.get("input", "")
        if not q:
            return {"history": ""}
        hits = self.tex.recall(q, session_id=self.session_id, top_k=self.top_k)
        history = "\n".join(f"- {h.text}" for h in hits.hits.turns)
        return {"history": history}

    def save_context(self, inputs: dict[str, Any], outputs: dict[str, str]) -> None:
        self.tex.conversations.remember(
            [
                {"role": "user", "text": inputs["input"], "timestamp": now_iso()},
                {"role": "assistant", "text": outputs["response"], "timestamp": now_iso()},
            ],
            session_id=self.session_id,
        )

    def clear(self) -> None:
        # No-op — Tex memory persists by design
        pass
```

`BaseChatMemory` is a Pydantic model, so declare fields instead of overriding `__init__`. Use it like any other LangChain memory:

```python
chain = ConversationChain(
    llm=ChatOpenAI(),
    memory=TexChatMemory(tex=tex, session_id="chat-1"),
)
```
